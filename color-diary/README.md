# Color Diary — 封面图片生成器

一个优雅的分割式封面图片生成工具，可以从照片中提取主色调并创建精美的封面布局。

## 功能特性

- 📷 **图片/视频上传** — 支持 JPEG、PNG、GIF、WebP 等图片格式
- 🎨 **智能取色** — 自动从上传的图片中提取主色调作为背景
- ✂️ **分割布局** — 创建上下分割的封面风格，图片与色块交相辉映
- ✏️ **自定义文字** — 添加标题和日期，支持多种字体选择
- 🎞️ **颗粒纹理** — 添加复古胶片颗粒效果
- 🌈 **渐变背景** — 支持双色渐变过渡
- 🔄 **翻转布局** — 自由切换图片与颜色的上下位置
- 📱 **移动适配** — 完美的移动端体验
- 🌐 **中英双语** — 支持中文和英文界面
- 📥 **PNG 导出** — 一键导出高质量封面图片

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 使用方法

1. **上传图片** — 点击中央上传区域或拖拽文件
2. **自动取色** — 上传后工具会自动提取图片主色调
3. **调整布局** — 拖动分割线调整图片与色块比例
4. **添加文字** — 输入标题和日期，或点击「随机标题」获取灵感
5. **精细调节** — 调整字体大小、颜色、颗粒强度等
6. **导出保存** — 点击「导出 PNG」下载封面图片

## 技术栈

- **React 18** — UI 框架
- **Vite** — 构建工具
- **Tailwind CSS** — 样式框架
- **node-vibrant** — 图片颜色提取

## 字体支持

- **打字机 (Courier)** — 经典打字机风格
- **衬线 (Serif)** — 优雅的中文衬线字体
- **无衬线 (Sans)** — 现代简洁风格
